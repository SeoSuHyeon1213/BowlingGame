# Low Poly Bowling & Billiards Pack (Free)
by reodesuxz

27 low poly bowling alley and billiards hall models: lanes, pins, balls, pool tables, cues, arcade lounge props.

## Contents
- FBX/  - one .fbx per model (Unity, Unreal, Godot, Blender)
- GLB/  - one .glb per model (Godot, three.js, Babylon.js, web)
- OBJ/  - one .obj + .mtl per model
- BowlingBilliards_AllAssets.blend - every model in one Blender file (Blender 4.3+)

## Specs
- Total: 4472 triangles for all 27 models (8-1360 tris each)
- Flat-shaded, simple shared materials (no textures needed)
- Real-world scale in metres, pivot at the base centre
